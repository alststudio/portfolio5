# Bali Travel — Landing Page Pemesanan Wisata Bali

Demo landing page pemesanan perjalanan satu file untuk brand fiktif **Bali Travel**, diterbitkan dengan GitHub Pages dari folder `docs/`.

## Isi halaman

- **Hero sinematik tiga slide** — foto Tanah Lot saat matahari terbenam, vila tropis dengan kolam menghadap sawah, dan gerbang candi Bali — dengan judul raksasa bergradasi, awan volumetrik yang bergerak (blend mode *screen*), serta transisi *wipe* berkabut dari kanan ke kiri yang berganti otomatis setiap 5,2 detik.
- **Deretan thumbnail bundar** dengan cincin konsentris dan caption yang bergeser mengikuti slide aktif.
- **Bilah pencarian yang berfungsi** — popover kalender untuk memilih tanggal check-in/check-out dan popover jumlah tamu (dewasa dan anak-anak).
- **Delapan kartu Rekomendasi Penginapan** di berbagai area Bali (Ubud, Tegallalang, Seminyak, Uluwatu, Canggu, Nusa Dua, Jimbaran, Sanur) dengan harga per malam dalam Rupiah dan tombol favorit.
- **Halaman detail properti** dengan transisi *shared-element* dari kartu, kartu pemesanan (tombol “Pesan Sekarang”), fasilitas, ulasan, dan penginapan serupa.
- Kursor khusus, navigasi yang berubah solid saat scroll, efek parallax awan, dan tata letak responsif untuk tablet dan ponsel.

Seluruh konten berbahasa Indonesia dan semua foto menggambarkan Bali, Indonesia. Harga merupakan data contoh.
